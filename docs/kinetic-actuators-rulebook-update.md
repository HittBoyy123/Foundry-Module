# Gate Attenuators — pending release

Six craftable attenuator tiers follow the configured spell-focus progression. Default bonuses to both impulse attack rolls (including Elemental Blast) and impulse DCs are **+0 / +1 / +2 / +3 / +4 / +5** for Tiers 1–6.

Actuators must be worn. Only the strongest worn attenuator applies. The bonus is an item bonus and does not stack with other item bonuses to that statistic. Actuators do not grant spell attack/DC bonuses, extra impulse damage or native gate-attenuator activated abilities. Even Tier 6 has no Constitution or apex benefit; a Constitution apex item remains separate.

| Recipe component | Requirement |
| --- | --- |
| Lead | Enchanting |
| Core | 2 Mana Gem units at the selected tier |
| Frame | 1 Metal or Wood unit, minimum core tier minus two (minimum Tier 1) |
| Named support | Blacksmithing for metal, Carpentry for wood |

Use normal Work Block DCs, tool bonuses, teamwork, crafting progress and manual Edge/Masterstroke resolution. Compatible equipment Masterstrokes are allowed; spell-focus-specific benefits do not apply to attenuators.

The six entries are in **Wrathmaker Crafting Items**. Existing local installations can use **Refresh All** after reloading to add them. Drag a Gate Attenuator into the Workbench and select its core tier before crafting.
