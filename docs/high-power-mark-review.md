# High-power Artisan Mark review

All 253 existing Marks have been reviewed: 11 professions, each with five universal Marks and three specialisations containing six Marks each. IDs, names (including the preceding 23 revisions), sources, grades and maker records remain stable. This is intentionally high-power Wrathmaker homebrew, not standard PF2e balance.

## Notable changes

- **Defence:** Fortified Frame reaches four times pre-Mark item HP at Tier 6. Ceramic Plate grants 40 HP and 5 Hardness per Core Tier to armor or shields. Maximum-HP Marks now offer substantial wearer durability without per-turn temporary-HP refills.
- **Weapons outside blacksmithing:** Glassmaking's Arcane Conductor adds two base weapon dice. Beam Splitter offers a reaction for a second ranged Strike against another target. Carpentry and dragon leatherwork each have three-die Over-Striking paths.
- **Magic:** Over-Potency is capped at +2 per Mark beyond existing bonuses: Overlord Matrix adds +2 weapon accuracy or spell attack/DC, Horizonstring adds +2 conditional ranged accuracy, and Sovereign Refraction adds +2 spell DC. Different Marks still stack; Overcharged Matrix cannot increase these contributions. Damage-dice upgrades are unchanged.
- **Social and exploration:** tailored presentation, maps, optics, trophies and scholarship now have meaningful +5 or tier-scaled benefits, with their subjects and circumstances preserved.
- **Alchemy and projects:** stronger healing doses, batch efficiency, modular construction and resource planning have explicit rounding, original-input limits and exclusions against recursive recovery. These project and consumable effects require manual resolution unless expressly implemented.
- **Temporary HP:** recurring pools mostly became maximum HP. The few 10-point Artisan buffers are separate manual pools, not replacements for class temporary HP. Spend the Artisan buffer before ordinary temporary HP, then actual HP; each grant expires as written. Multiple different Mark buffers may coexist. Reusing the same grant does not add or refill it without its stated activation and frequency allowance.

## Shared adjudication

Flat Artisan modifiers are untyped and stack with different Marks. Existing one-zero-Capacity-Mark and total Capacity rules remain. Resistance still uses PF2e's highest applicable source; it is not summed. Durability percentages add against the same pre-Mark base rather than multiplying one another. Mark healing and resource recovery cannot create recursive recovery loops.

For an activation referring to the higher class or spell DC, choose the user's highest available one at activation. NPCs without either need a GM-assigned DC recorded before use. A once-per-encounter ability refreshes for a genuine new encounter, not by repeatedly starting combat or re-equipping. Otherwise use the stated daily or charge limit.

The current review updates descriptions throughout the compendiums and profession guide. It does **not** mean every special effect is fully automated. Supported passive numerical rules apply through the existing system integration; conditional rules expose item-specific toggles. The Workbench labels numerical versus manual resolution. All 61 declared activations generate native action readouts, but those entries do not spend charges, choose targets or apply their damage automatically. Structure and Kingdom benefits remain descriptive. No automatic temporary-HP ledger is installed.

Base damage-dice automation follows the PF2e project's documented DamageAlteration model: https://github.com/foundryvtt/pf2e/wiki/Quickstart-guide-for-rule-elements#damage-alteration

Imported journals are copies: reimport the updated guide or update an existing copy deliberately. Existing known Mark descriptions refresh when normalised; maker and configured choices are retained. Review previously crafted equipment whose eligibility changed before play.
